# How to Launch Crownfall Tactics

## Game Location
**Directory:** `/mnt/agents/output/crownfall-tactics`

## Quick Start Options

### Option 1: Python Launcher (Recommended - Cross Platform)
```bash
cd /mnt/agents/output/crownfall-tactics
python3 launch_game.py
```
Or on Windows:
```cmd
cd /mnt/agents/output/crownfall-tactics
python launch_game.py
```

### Option 2: Windows - Double Click
Navigate to `/mnt/agents/output/crownfall-tactics` and double-click:
- `START_GAME.bat`

### Option 3: Linux/Mac - Terminal
```bash
cd /mnt/agents/output/crownfall-tactics
./start_game.sh
```

### Option 4: Manual (Any Platform)
```bash
cd /mnt/agents/output/crownfall-tactics
python3 -m http.server 10000
```
Then open: http://localhost:10000

## Game URL
Once launched, visit: **http://localhost:10000**
